# SignLingo 학습 MVP — 첫 번째 레슨 흐름

첫 버전의 학습 시스템은 기존 Motion Lab과 Practice Mode를 재사용하는 수직적인 기능 검증입니다.

## 학습 흐름
1. **학습하기**에서 "나의 첫 수어 표현"을 엽니다.
2. 관리자가 정확성을 확인한 MotionClip JSON을 브라우저에서 선택합니다. 선택 자료는 로컬 메모리에만 보관되며, 자동으로 저장·업로드되지 않습니다.
3. 선택적으로 JSON에 기재된 파일명과 크기가 일치하는 원본 영상을 연결합니다.
4. 3D 시범을 반복 재생하고 "시범 확인 완료"를 선택합니다.
5. "카메라로 따라 하기"를 누르면 기존 Practice Mode로 기준 동작을 전달합니다.
6. 촬영 또는 기존 동작 JSON 불러오기로 관측된 동작 차이를 비교하고, "연습 결과 검토 완료"로 돌아옵니다.
7. 브라우저 localStorage에는 **관찰 기록·연습 횟수·추적 근거 수준·마지막 연습 시각만** 기록합니다.

## 중요한 제한
- 배포 저장소에는 전문가가 검증한 한국수어 동작 및 영상 자산이 아직 없습니다. "첫 레슨"은 완성된 수어 정답 사전이 아니라 **직접 검증된 자료를 붙여 시험하는 학습 틀**입니다.
- 사용자가 붙인 임의의 동작 JSON을 공식적으로 맞는 수어라고 인정하지 않습니다.
- 동작 비교 결과는 수어 정답 판정·시험 통과·자격 검정 결과가 아닙니다.
- 지문자, 일상 표현, 문장 등 후속 과정은 "준비 중"입니다. 가짜 애니메이션을 연결하지 않았습니다.
- 원본 영상과 기준 MotionClip은 새로고침 후 다시 선택해야 합니다. 학습 기록만 해당 브라우저에 남습니다.
- 여러 사용자/여러 장치 동기화, 검수 프로세스, 저작권 허가 자산 등록은 다음 단계에서 설계해야 합니다.
- 상체 인식과 녹화 후 추론의 기존 제약은 변경되지 않았습니다.

## 기존 기능 유지
- 동작 복원, 진단 패널, 웹캠/영상 분석, 기존 JSON 규격 및 GitHub Pages 배포 그대로 유지
- 학습 UI는 한국어를 기본으로 하며, 동작의 언어적 정당성은 아직 검증하지 않음
