# 검수 규칙

2026-10-15 저장소 소유자가 정한 규칙입니다.

## 피드백이 곧 두 검수 결과

- 학습 콘텐츠는 공개 전에 두 검수(3D 복원 검수, 한국수어 검수)를 받습니다. 저장소 소유자는 개정판 후보를 검수자 B와 **함께** 봅니다.
- 소유자가 대화나 PR에서 후보에 대해 승인하는 피드백("좋다", "충분하다", "공개")을 남기면, 그 피드백을 그 개정판의 **두 검수 승인**으로 기록합니다. 매번 "두 검수가 끝났다"고 따로 말할 필요가 없습니다.
- 수정 요청이 담긴 피드백이면 승인하지 않고 고친 뒤 다시 보여 줍니다. 한 표현을 승인하고 다른 표현은 고치는 식으로 표현마다 따로 판단합니다.
- 피드백이 어느 개정판에 대한 것인지는 패키지(`private-data/<id>/entry.json`)의 현재 개정판으로 정합니다. 개정판 번호를 따로 알려 줄 필요가 없습니다.

## 기록 방법

```sh
npm run content -- approve --publish --feedback "<피드백 원문>" private-data/ksl-meet private-data/ksl-thanks
```

- 대상 해시, 동작 파일·제약 조건 해시를 명령이 계산해 `docs/content-reviews/review-<날짜>.md`(같은 날 두 번째부터 `-2`, `-3`)를 만듭니다. 손으로 해시를 적지 않습니다.
- 두 검수를 그 기록으로 승인하고(검수자 이름과 자격은 `src/content/reviewers.json`), `ready-to-publish`로 옮긴 뒤 `--publish`면 바로 공개합니다.
- 기록의 피드백 원문은 고치지 않습니다. 설명·변이·자산·제약 조건이 바뀌면 승인은 자동으로 무효가 되고 다시 검수합니다.

## 이 규칙 이전의 기록

개정판 1·2의 기록(`course1-*`)은 검수마다 따로 쓴 문서이며 그대로 둡니다.
